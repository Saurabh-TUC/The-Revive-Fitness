# The Revive Fitness – Gym Website

Official website for **The Revive Fitness**, a unisex gym in Mango, Jamshedpur, Jharkhand, India.

A fast, mobile-friendly, single-page website built with plain HTML, CSS and JavaScript. No framework, no build step.

## Project structure

```
.
├── index.html      # The website (HTML, CSS and JS)
├── images/         # Gym photos (gym-1.jpg ... gym-15.jpg)
└── README.md
```

## Run locally

Open `index.html` in any web browser.

## Deploy on GitHub Pages

1. Keep `index.html` and the `images/` folder in the root of the `main` branch.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
4. The site goes live at `https://saurabh-tuc.github.io/The-Revive-Fitness/`.
